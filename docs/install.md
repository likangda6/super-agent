# 安装

本项目需要 **Node.js 22.19+** 和 **pnpm**。

## 环境要求

- Node.js 22.19 或更高版本
- pnpm

## 安装步骤

1. 确认 Node.js 版本不低于 22.19：

   ```bash
   node --version
   ```

2. 安装 pnpm（已安装可跳过）：

   ```bash
   corepack enable
   ```

   若环境中没有 Corepack，也可以使用 npm 全局安装：

   ```bash
   npm install -g pnpm
   ```

3. 验证安装结果：

   ```bash
   node --version   # v22.19.0 或更高
   pnpm --version
   ```
